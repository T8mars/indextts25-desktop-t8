## 0.26.5 更新内容

- 修复载入角色后自动勾选“更新所选角色”，导致添加第二个角色时误改名、覆盖第一个的问题。
- 新增“＋ 新建角色”按钮，清空填写区并退出更新模式，已有角色保留。
- 新增遇到同名角色时提示，避免直接覆盖原音色；主动勾选更新仍支持修改、改名已有角色。
- 保存后显示音色库角色总数，页面与 README 补充多角色使用说明。

## 怎么添加多个角色

1. 打开“角色音色库”，点击“＋ 新建角色”。
2. 填写不同的角色名称，上传对应的音色参考音频，点击“保存角色音色”。
3. 重复以上步骤添加其他角色。新增时保持“更新所选角色”不勾选。
4. 在“多角色 / 批量台词 / SRT”使用 `角色名称|台词|ZH|1.0`，系统按名称匹配音色。

如果需要修改或改名原角色，先选择并载入该角色，再主动勾选“更新所选角色”后保存。
