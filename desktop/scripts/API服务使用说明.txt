T8star-Aix · IndexTTS 2.5 常驻 API 服务
==========================================

1. 先打开桌面程序，选择模型目录，并在“本地 API 服务”中设置端口、默认音色。
2. 双击“启动API服务.cmd”。请保留控制台窗口；看到服务地址后即可持续调用。
3. 双击“查看API服务状态.cmd”可检查状态；双击“停止API服务.cmd”可安全停止。

默认地址：http://127.0.0.1:7861
接口文档：http://127.0.0.1:7861/docs
OpenAI 兼容接口：POST http://127.0.0.1:7861/v1/audio/speech

鉴权：Authorization: Bearer <桌面启动器中显示的 API Key>
也支持：X-API-Key: <API Key>

OpenAI 兼容请求示例：
{
  "model": "tts-1",
  "input": "你好，这是一段 API 语音。",
  "voice": "桌面音色库中的角色名称",
  "response_format": "mp3",
  "speed": 1.0
}

音色必须先保存到桌面音色库；API 不接受任意本地文件路径，避免外部调用读取隐私文件。
生成文件默认保存到桌面的输出目录，并出现在生成历史中。
局域网监听会让同一网络内的设备可访问，请务必保管 API Key，并仅在可信网络使用。
